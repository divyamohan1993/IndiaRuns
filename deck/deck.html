The Problem

Recruiters drown in profiles — and still miss the right person.

  • Keyword filters match words, not fit. They rank by skill-count, so a buzzword-stuffed profile beats a quiet specialist who actually shipped the system.
  • The cost is two-sided: great candidates stay invisible, and recruiters burn hours on confident-looking non-fits.
  • Redrob's bet is an AI brain for hiring — read a job description and rank like a great recruiter would, by understanding who fits, not who matched the most strings.
And this dataset makes that hard on purpose.

The Algorithm

The hybrid funnel: recall → judge → fuse → gate.

  • 1 · Recall first-pass. 0.30·dense + 0.25·bm25 + 0.45·rule over all 100K → top 1,200, force-include AI-titled & strong-evidence, drop honeypots.
  • 2 · LLM re-rank the shortlist only — where ~80% of the metric lives. 1,226 real meta/llama-3.3-70b-instruct judgments on the full shortlist.
  • 3 · Blend / LTR fusion — monotone-constrained. We ship the safer one.
  • 4 · Behavioral × [0.80–1.12] — modulates, never dominates. Sentinels never penalize.
  • 5 · Honeypot hard-gate + live re-verify of survivors.

Recall gate — measured, not assumed

100% of proxy-Tier-5 (700) and 100% of proxy-Tier-4 (216) land inside the 1,198-id shortlist. Nothing good is lost before the LLM sees it.

Ship the safer model

Fixed-weight blend won 5-fold CV-NDCG@10 1.0000 vs learned LTR 0.766 → the blend ships. The monotone LTR path is fully built and reproducible.

# shortlisted (the only rows that reach top-100) base_fit = 0.50·S_llm + 0.20·S_dense + 0.18·S_rule + 0.12·S_bm25 margin = blend(features) → × anti_trap_caps → × behavioral → honeypot GATE

Anti-Keyword Reasoning

We rank by what you did — not what you listed.

  • Embed the career narrative, weighting descriptions above the skills array — so stuffing the skills list cannot move the vector.
  • Evidence features read from descriptions: shipped a ranking/search/recsys system, built embeddings retrieval, designed NDCG/MRR/MAP eval, deployed to production.

The role/skill-mismatch cap — × 0.15

A non-engineering current title that lists an AI skill is multiplied down by 0.15. This is the direct counter to the baseline's HR-Manager-#1 failure — and it acts as a deterministic floor under the LLM, so model optimism can never out-vote a structural disqualifier.

A Marketing Manager's campaign text embeds far from the role — regardless of stuffed skills.

Honeypot Defense

Three deterministic layers — no trap survives.

Clean-201 hard exclude

Rebuilt from high-precision structural impossibilities only — gated to -inf:

career_span_exceeds_yoe3= exactly201

Live re-verify + top-10 paranoia

Every survivor reaching the top-300 is re-checked; each top-10 slot must show real shipping evidence.

The critical non-check

Salary min > max fires on 18.9% of the pool — it is a dataset norm, not a trap. Flagging it would delete a fifth of the candidates, including genuine fits. We deliberately do not flag it.

AI Usage & The Compliance Boundary

Heavy AI everywhere it helps — never on the graded path.

NVIDIA — Plane A

Hosted embeddings + a 70B-class instruct re-rank of the shortlist and fact-validated reasoning. Full path built; degrades cleanly with no key.

LLM judging

1,226 real meta/llama-3.3-70b-instruct judgments on the full shortlist; fact-validated reasoning lines. A claude -p CLI backend + deterministic fallback — runs with or without any key.

GCP — Plane C

Cloud Run for API + web, Secret Manager for the key, optional Vertex for Plane A. Documented and credential-gated — never needed to grade.

The boundary

Every AI / network call lives in Plane A or C. The graded rank.py makes zero network, GPU, or LLM calls — proven by a no-socket test and a --network none run. NVIDIA and GCP are quality multipliers, never dependencies.
